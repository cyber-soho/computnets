Security Posture

Network security is a posture you maintain, not a product you buy. This section covers the foundational CIA Triad, the critical migration from Telnet to SSH, and securing the physical Layer 2 perimeter.

The CIA Triad

Confidentiality

Only authorized eyes see the data.

Action: Encryption everywhere (HTTPS, SSH), Strong passwords, MFA.

Integrity

Data is not altered without permission.

Action: HMAC checks, SSH-2 implementation.

Availability

The service answers when legitimate users ask.

Action: Port-security (prevents rogue DHCP/loops), Backups, Patching.

Protocol Migration: Telnet vs SSH-2

☠️ Telnet (Dead in 2026)

  • • Cleartext over TCP/23
  • • Wireshark sees every keystroke
  • • No integrity check (tamper-prone)
➔

🛡️ SSH-2 (The Standard)

  • • TCP/22, AES + ChaCha20 ciphers
  • • HMAC integrity checks
  • • Key-based auth (RSA 2048+ bits)
  • • Critical: transport input ssh

⚙️ Backups (TFTP & Beyond)

  • The Reality Check One typo erases a route in 0.2s. Rebuilding at 2 AM relies on tested backups.
  • Legacy Baseline: TFTP (UDP 69) No auth, no encryption. Use ONLY inside a secured management VLAN.
  • Modern Standard SCP over SSH, SFTP, or HTTPS pushes to a central server.
Backup Hygiene Checklist: Run nightly, stamp filename with date/host, verify file size > 1KB, email daily reports.

📚 Documentation Standards

Triage & The OSI Matrix

A method beats a genius without one. Before touching the keyboard, ask: "What changed in the last 24 hours?" Then, apply a structured methodology using the OSI model as your compass.

Methodologies

⬆️ Bottom-up

Start L1, climb to L7. Best when hardware/cabling is suspected.

⬇️ Top-down

Start L7, descend to L1. Best for application-level user complaints.

➗ Divide-and-conquer

Start in the middle (L3/L4). Halve the search space based on pings.
